# example_xiaomei — 範例前任 Skill (致敬 ex-skill)

> 此目錄為致敬 [perkfly/ex-skill](https://github.com/perkfly/ex-skill) 的範例結構。
> 實際使用中，`exes/` 下的內容均為 gitignored 私人資料。
>
> Self-Mirror 的核心輸出存放於 `twin_profile/` 而非此處。

---

## 關於此範例

`example_xiaomei` 是一個示範用的前任 Skill 結構，
展示如果你同時想用 ex-skill 風格「蒸馏某人」時，資料夾應有的樣貌。

Self-Mirror 的核心方向不同：
- **ex-skill** → 把「她」蒸馏成 AI Skill
- **Self-Mirror** → 把「你自己」蒸馏成數位雙生

但兩者的技術架構一脈相承，
Self-Mirror 向 perkfly/ex-skill 的創意精神致敬。

---

## 結構說明

```
exes/example_xiaomei/
├── README.md          ← 本說明文件
├── persona.md         ← 人格設定（示範）
└── memories.md        ← 共同記憶（示範）
```

真實的前任 Skill 應包含：
- `persona.md`：5層人格結構（表達風格、情緒邏輯、關係行為…）
- `memories.md`：共同記憶時間線、日常儀式、偏好習慣
